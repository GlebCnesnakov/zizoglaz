# Running Biomechanics — MVP

Прототип системы для количественной оценки техники бега по обычному видео.

## Что уже умеет MVP
1. Загружает MP4.
2. Извлекает 2D-позу бегуна через MediaPipe Pose.
3. Сглаживает координаты ключевых точек.
4. Рассчитывает:
   - угол в колене;
   - угол в тазобедренном суставе;
   - угол в голеностопе;
   - наклон туловища;
   - вертикальную позицию таза;
   - примерную частоту шагов;
   - левую/правую асимметрию по амплитуде коленного угла.
5. Сохраняет CSV с покадровыми параметрами.
6. Строит графики.
7. Формирует краткий JSON-отчёт.
8. Может сохранить видео с наложенным скелетом.

## Быстрый запуск

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt

python -m src.main --video data/raw/mini_run.mp4
```

Результаты появятся в `results/`.

## Важное ограничение
Это исследовательский MVP, а не медицинская система и не готовый классификатор «правильная/неправильная техника».
Сначала система измеряет объективные биомеханические показатели. Критерии технической эффективности будем валидировать отдельно на выборке спортсменов.
